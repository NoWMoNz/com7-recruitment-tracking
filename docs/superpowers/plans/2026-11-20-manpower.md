# กำลังพล (Quota / Actual) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Keep HR's Quota/Actual per branch × position and show them on a new `/manpower` page with a comparison to open requisitions.

**Architecture:** New `Quota` tab written by the HR import; a pure domain module (`manpower.ts`) builds per-branch rows (with per-position detail), filters and summarises; a page, an Excel export and a menu item sit on top.

**Tech Stack:** Next.js App Router (follow existing pages), TypeScript, Vitest, MemoryRepo, ExcelJS.

**Spec:** `docs/superpowers/specs/2026-11-20-manpower-design.md`

## Global Constraints

- Do not commit unless the user asks.
- Thai UI copy, same look as the other pages (pill filters, `Dropdown`, glass cards).
- Overwrite, not history: the import file's `Quota` tab replaces the sheet's `Quota` tab.
- Run `npx tsc --noEmit`, `npx eslint <changed files>`, `npx vitest run` before a task is called done.

## Review Focus

- A position with Quota 0 and Actual > 0 (over, no quota) and one with Quota > 0 and Actual 0 (empty store) both count correctly. (Task 2)
- A branch missing from `Branches`, or `Closed`, or out of the viewer's scope never appears; totals match the visible rows. (Task 2)
- Requisitions not yet effective (future request date) and closed ones are not "open in system". (Task 2)
- A hand-typed non-number in `quota`/`actual` must not crash the page (parsed as 0 by the sheet layer) — check the export too. (Task 3)

### Task 2: Domain — `manpower.ts`

**Files:** Create `src/lib/domain/manpower.ts`; Test `tests/domain/manpower.test.ts` (helpers from `tests/domain/helpers.ts`).

**Interfaces:**
- Consumes: `QuotaLine`, `Requisition`, `Branch`, `Position`, `User`; `inScope`, `buOf/rmOf/amOf`, `ON_PROCESS`.
- Produces:
  ```ts
  export type ManpowerStatus = "short" | "over" | "full";
  export type OpenMatch = "match" | "fewer" | "more"; // open == short / open < short / open > short
  export interface ManpowerPosition { positionCode: string; positionName: string; quota: number; actual: number; short: number; over: number; open: number; match: OpenMatch }
  export interface ManpowerRow { branchCode: string; branchName: string; bu: string; rm: string; am: string; region: string; province: string; quota: number; actual: number; short: number; over: number; open: number; status: ManpowerStatus; match: OpenMatch; positions: ManpowerPosition[] }
  export interface ManpowerFilter { bu?: string; rm?: string; am?: string; region?: string; status?: ManpowerStatus; q?: string }
  export function buildManpowerRows(d: { quota: QuotaLine[]; requisitions: Requisition[]; branches: Branch[]; positions: Position[] }, viewer: User, today: LocalDate): { rows: ManpowerRow[]; closedBranches: number };
  export function filterManpowerRows(rows: ManpowerRow[], f: ManpowerFilter): ManpowerRow[];
  export function summarizeManpower(rows: ManpowerRow[]): { branches: number; quota: number; actual: number; short: number; over: number; full: number };
  ```

- [ ] **Step 1: Failing tests** with the spec's numbers: per-position `short/over` (PIA 3/1 → short 2; Part Time 0/2 → over 2; empty store 4/0 → short 4); branch `short`/`over` are sums so a surplus never cancels a shortage; status ขาด/เกิน/ครบ; `open` counts only `ON_PROCESS` requisitions of that branch+position with `request_date <= today`; `match` for equal/fewer/more; rows sorted by `short` descending then branch name; a branch not in `Branches`, a `Closed` branch (counted in `closedBranches`) and an out-of-scope branch never appear; `filterManpowerRows` by bu/region/status and `q` on branch name/code; `summarizeManpower` totals equal the sum of the rows.
- [ ] **Step 2: Run** — FAIL. **Step 3: Implement.** Positions of a row sorted by `short` desc then name; position name from `Positions` or the code. **Step 4: Run** — PASS, `tsc` clean.
